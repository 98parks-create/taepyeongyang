# 태평양애드 기업 웹사이트

**광고물 제조기업 '주식회사 태평양애드'의 공식 웹사이트** (팀 프로젝트)

LED디스플레이, 옥외광고, 사인물을 제조하는 실제 기업의 웹사이트를 제작했습니다.
실존 기업의 요구사항을 반영해 만든, 실사용 목적의 프로젝트입니다.

## 주요 기능

- 기업 소개 및 시공 사례 포트폴리오
- GSAP 기반 인터랙티브 애니메이션
- Gemini API 기반 고객 상담 챗봇

## 기술 스택

- **Frontend**: Vanilla JavaScript, HTML/CSS
- **Animation**: GSAP
- **Backend / DB**: Firebase
- **AI**: Gemini API

## 담당 역할

### AI 상담 챗봇 개발 및 환각(hallucination) 문제 해결

**문제**: 챗봇이 회사가 제공하지 않는 서비스나 잘못된 정보를 사실처럼 답변하는 환각 현상 발생. 기업 웹사이트에서 잘못된 안내는 실제 고객 피해로 이어질 수 있는 문제였습니다.

**과정**: 어떤 질문 유형에서 잘못된 답변이 나오는지 사례를 모아 분류. 회사 정보에 없는 내용을 물었을 때 모델이 임의로 답을 지어내는 패턴을 확인했습니다.

**해결**: 답변 범위를 회사 제공 정보로 제한하는 프롬프트 설계, 범위를 벗어난 질문은 "상담 연결" 안내로 유도하도록 응답 구조 변경.

**결과**: 잘못된 정보 안내 문제를 해결하고, 실제 기업이 사용할 수 있는 수준의 챗봇으로 안정화.

## 배운 점

- 실제 기업의 요구사항을 듣고 기능으로 옮기는 과정
- AI를 고객 접점에 쓸 때는 "모르면 모른다고 답하게" 만드는 설계가 필수라는 것
