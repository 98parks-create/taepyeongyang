# 태평양애드(TAD) 기업 웹사이트

태평양애드(TAD)의 공식 기업 홈페이지입니다. 옥외광고 전문 기업의 브랜드 아이덴티티를 반영한 정적 웹사이트입니다.

## 페이지 구성

| 페이지 | 설명 |
|--------|------|
| **HOME** | 메인 히어로 섹션 (배경 영상) |
| **COMPANY** | 대표 인사말, 주요 사업, 비전, 연혁, 오시는 길 |
| **PROCESS** | 광고 제작 프로세스 소개 |
| **PORTFOLIO** | 시공 포트폴리오 갤러리 |
| **CONTACT** | 견적 문의 폼 및 연락처 |

## 기술 스택

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Animation**: GSAP (GreenSock) + ScrollTrigger

## 프로젝트 구조

`	ext
taepyeongyang/

├── contact.html       # 문의하기

├── contact.css        # 문의 페이지 스타일

`	ext

## 실행 방법

별도의 빌드 없이 home.html을 브라우저에서 열면 바로 확인할 수 있습니다.
